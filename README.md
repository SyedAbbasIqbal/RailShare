# RailShare – Online Train Ticket Sharing and Booking System

## Project Overview
RailShare is a web-based train ticket sharing and booking application developed using Java, JSP, Servlets, JDBC, and MySQL.

The application provides separate roles for Buyers, Sellers, and Administrators to manage train ticket listings, bookings, transfers, and related activities.

## Features

### Buyer
- User registration and login
- Browse available train tickets
- Book tickets
- View purchase history
- Download ticket details

### Seller
- List train tickets for sharing
- Manage listed tickets
- View ticket activity

### Admin
- Admin dashboard
- Manage users and tickets
- Manage fares
- View reports and analytics
- Track ticket transfer history

## Technologies Used
- Java 21
- JSP and Servlets
- JDBC
- MySQL
- Maven
- Apache Tomcat 9
- HTML, CSS, JavaScript

## Project Requirements
- JDK 21
- Apache Tomcat 9
- MySQL Server
- Eclipse IDE
- Maven

## Database Setup
1. Create a MySQL database named `railshare`.
2. Configure the database environment variables:
   - `RAILSHARE_DB_URL`
   - `RAILSHARE_DB_USERNAME`
   - `RAILSHARE_DB_PASSWORD`
3. Configure the database tables using the project's database schema.

## Running the Project
1. Clone or download this repository.
2. Import the project into Eclipse as an existing Maven project.
3. Configure the required database environment variables.
4. Update the Maven project.
5. Deploy the project on Apache Tomcat 9.
6. Open `http://localhost:8080/RailShare/` in your browser.
